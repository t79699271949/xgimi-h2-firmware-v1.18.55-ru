# AGENTS.md — правила для ИИ-агентов и разработчиков

Этот файл — для ИИ-ассистентов (Claude Code, Codex, Cursor и т. п.) и для людей, которые
собираются менять образ. Прочитайте **целиком** до любых правок: здесь перечислены ограничения,
нарушение которых превращает проектор в кирпич.

## 2. Жёсткие правила (нарушение = кирпич или потеря данных)

### 2.1 Загрузчик (bootloader / MStar LK) — НЕ ТРОГАТЬ НИКОГДА

Экран меню обновления (лупа, стрелка вверх, китайские подписи) рисует **загрузчик**, а не Android.
Его нет в `system.img`. Любая правка = проектор не включается, восстановить нечем (нет
`recovery.img`, нет UART-доступа).

Китайские подписи в меню обновления оставлены **осознанно**. Не «исправляйте» это.

### 2.2 `e2fsck -fy` на этом образе — НЕ ЗАПУСКАТЬ

Портит файловую систему образа (проверено). Для проверки содержимого используйте только
`debugfs -R "..."`.

### 2.3 Размер образа — не больше 371 077 блоков (1 519 931 392 байт)

Больше — загрузчик не примет образ. Следите за свободным местом при добавлении файлов.

### 2.4 APK нельзя класть в `/system/app`

Проектор с APK в `/system/app` **не загружается** (проверено на C19). Приложения кладутся только в
`/system/etc/restore-apps/` и устанавливаются хуком через `pm install -r`.

### 2.5 Шелл-скрипты только с LF

Cкрипт с переносами `\r\n` **молча не запускается**: `#!/system/bin/sh\r` — интерпретатор не
найден. Симптом: система грузится, но нет ADB, агента, чистки, отключения клавиатуры.
**Проверяйте перед вшиванием:**

```python
assert open(path, "rb").read().count(b"\r\n") == 0
```

Исторический пример: c20 = LF (работал), c30/c31 = CRLF (не работали), c34 = LF (работает).

### 2.6 `desc.txt` в анимациях — только LF

То же самое: `bootanimation.zip`/`shutdownanimation.zip` с `\r\n` в `desc.txt` не проигрывается.

### 2.7 Русификация сторонних APK — только overlay (RRO)

Пересборка системных APK ломает подпись и меню. Правильный путь: `/vendor/overlay/ru-*.apk` с
`targetPackage` и строками (`values-ru`). Сторонние приложения (Aerial) overlay **не принимают** —
для них берётся APK с официальным русским.

### 2.8 Заголовок `.bin` — простой

Только `mmc erase.p system` + `mmc unlzo`. **Без** `set_config` и без
`recovery_wipe_partition data` (иначе сотрётся пользовательские данные и сломается загрузка).

### 2.9 Порядок операций в образе

Сначала **удалить** лишние пакеты/файлы, потом **добавлять** новые. Иначе не хватит места.

## 3. Как собрать образ

```bash
# 1. Копируем базу
cp fw/work/sys_c33.img fw/work/sys_c34.img

# 2. Правим через debugfs (только он, не e2fsck, не mount)
debugfs -w -R "write <host-file> /path/inside/image" fw/work/sys_c34.img
debugfs -w -R "sif /path mode 0100755" fw/work/sys_c34.img

# 3. Проверяем
debugfs -R "ls /vendor/overlay" fw/work/sys_c34.img

# 4. Упаковываем (pack.py + configs/custom11855.ini)
cd mbt && cp ../fw/work/sys_c34.img pack/system.img && python pack.py configs/custom11855.ini

# 5. Сверяем SHA и структуру (10 частей, footer 240, erase.p + unlzo)
```

Скрипт сборки конкретной версии — в `scripts/` (например `scripts/c34.sh`).

## 4. Что внутри образа

| Путь | Содержимое |
|---|---|
| `/vendor/overlay/ru-*.apk` | 12 overlay-пакетов с русскими строками (~2 100 строк) |

| `/media/shutdownanimation.zip` | русская анимация выключения (182 748 Б) |

| `/media/bootanimation.zip` | оригинальная (2 038 823 Б) — не менялась |

## 5. Диагностика на устройстве

ADB включается при загрузке: `adb connect <ip>:5555`. Агент мониторинга — `http://<ip>:8081`:

```
/cgi-bin/health    → {"status":"ok"}
/cgi-bin/status    → ts, temp_cpu_c, freq_khz, watt, throttled, uptime_s, mem_*
/cgi-bin/history   → история за 24 ч
```

Нормальные значения: температура 55–70 °C, частота 1.1–1.5 ГГц, `throttled` может быть 1 при
нагреве — это штатно.

Если ADB нет, а ping проходит: **хук не запустился** (см. 2.5), либо сеть есть, а UI не поднялся —
прошейте образ заново.

## 6. Чего в этом репозитории нет

- персональных данных, IP-адресов, MAC-адресов, серийных номеров;
- оригинальной прошивки XGIMI (её нужно брать у производителя);
- приватных ключей подписи.
