Android 6.0 / API 23, сборка `aosp_synsepalum_YN-userdebug`).

Основа — штатная прошивка **1.18.55**. Всё работает офлайн, из коробки и **сохраняется после сброса

а не установлены вручную.

## ⚠️ Совместимость: прочитайте до скачивания

**Подходит только для XGIMI H2** на платформе `synsepalum_YN` (в системе устройство определяется как
«XGIMI TV», SoC MStar, Android 6.0). Точная модель в имени официального файла прошивки — `XHAD01`.

### Китайская и глобальная версии — это разные системы

Сборка сделана на базе официальной прошивки **1.18.55 китайской ветки**: в системе нет сервисов
Google, но есть китайские компоненты XGIMI и `kuyun`. Глобальная версия H2 работает на **другой
системе**, и прошивки между собой **несовместимы** — XGIMI прямо пишет, что это «completely
different systems» и перепрошивка между регионами приводит к «booting issues, system crash».

| Вариант | Совместимость |
|---|---|
| XGIMI H2 (китайская версия, MStar, Android 6) | ✅ подходит |
| XGIMI H2 глобальная (другая система) | ❌ не прошивать |
| XGIMI H1 / H1s | ❌ не прошивать |
| XGIMI H2 Slim | ❌ не прошивать |
| XGIMI H3, Horizon, MoGo, Elfin, Halo, Aura | ❌ не прошивать |

### Как проверить свою модель

1. **Настройки → О проекторе** — модель и версия ПО.
2. **Имя официального файла прошивки**, который вы скачивали у XGIMI для своего устройства.
3. Внешне: H2 — это тот, у которого колонка Harman/Kardon и разрешение 1080p; H2 Slim — компактный.

**Если сомневаетесь — не прошивайте.** Неверный образ для другого региона или модели может
превратить проектор в кирпич без возможности восстановления.

## Требования

- Проектор XGIMI H2 (MStar). **Не** для других моделей.
- **USB-флешка, FAT32**, не менее 2 ГБ свободно.
- В корне флешки должен лежать ровно **один** файл `.bin`.
- Понимание того, что неудачная прошивка может превратить проектор в кирпич.

## Как прошить

Смотрите **[FLASHING.md](FLASHING.md)** — пошаговая инструкция простым языком.

Коротко: скопировать `.bin` на флешку FAT32 → вставить в проектор → зажать кнопку на корпусе →
запустить обновление → **вынуть флешку при перезагрузке**.
