# XGIMI H2 — русская прошивка 1.18.55 (сборка C34)

Неофициальная, сделанная сообществом **русифицированная прошивка для проектора XGIMI H2** (SoC MStar,
Android 6.0 / API 23, сборка `aosp_synsepalum_YN-userdebug`).

Основа — штатная прошивка **1.18.55**. Всё работает офлайн, из коробки и **сохраняется после сброса
к заводским настройкам**: русский интерфейс и восстановление приложений вшиты в системный образ,
а не установлены вручную.

> ⚠️ **Прошивайте на свой риск.** Это не официальный релиз XGIMI. Читайте [DISCLAIMER.md](DISCLAIMER.md).

## Что вы получаете

| Область | Результат |
|---|---|
| **Системный интерфейс** | Китайские меню заменены на русские (настройки, меню питания, шторка, ошибки, мастер первого запуска) |
| **Выключение / перезагрузка** | Анимации «Выключение…» / «Перезагрузка…» вместо `正在关机中...` / `正在重启中...` |
| **Лаунчер** | Aerial 2.15 (русский, в стиле tvOS) вместо китайского лаунчера XGIMI |
| **Локальный плеер** | Русский, проигрывает видео с USB-носителей |
| **HDMI-плеер** | Русский |
| **Файловый менеджер** | Русский (встроен — восстанавливается после сброса) |
| **Клавиатура** | LeanKeyboard (русская), китайская Sogou отключена |
| **Предустановленные приложения** | Zona, SmartTube, TermOne (терминал) — восстанавливаются автоматически после сброса |
| **Мусор удалён** | 39 пакетов: реклама, телеметрия, китайский магазин приложений, онлайн-кинотеатры CIBN, заставки, скины, транслирование экрана |
| **Агент мониторинга** | Небольшой HTTP-агент на порту 8081: температура CPU, частота, история (опционально) |
| **ADB** | Включается при загрузке, порт 5555 |
| **Офлайн-распознавание речи** | Сервис Vosk `small-ru` установлен и настроен (нужен внешний USB-микрофон — встроенный микрофон не подключён в аудиополитике проектора) |

## Требования

- Проектор XGIMI H2 (MStar). **Не** для других моделей.
- **USB-флешка, FAT32**, не менее 2 ГБ свободно.
- В корне флешки должен лежать ровно **один** файл `.bin`.
- Понимание того, что неудачная прошивка может превратить проектор в кирпич.

## Как прошить

Смотрите **[FLASHING.md](FLASHING.md)** — пошаговая инструкция простым языком.

Коротко: скопировать `.bin` на флешку FAT32 → вставить в проектор → зажать кнопку на корпусе →
запустить обновление → **вынуть флешку при перезагрузке**.
